# American Living SK System Architecture & Living Blueprint

## 1. Platform & Tech Stack
- **Frontend:** React + Vite, Tailwind CSS, Radix UI, Framer Motion, Lucide icons.
- **Backend & Data:** Base44 Platform + Edge Functions.
- **Role:** Web & Customer Portal / Configurator for American Living SK.

## 2. Standard Operational Guidelines
- **Clean Context Execution:** Complex features must be isolated into subtasks executed by fresh-context workers.
- **Strict Verification:** Build, API, and console verifications required prior to task sign-off.
- **Git Sync Discipline:** Intermediate iterations remain local. Single push at completion to protect Base44 sync.
